# DoDorithm's!

Welcome to Dodo's Algorithmic Adventure, a story-driven platformer where every obstacle is a playful, hands-on algorithm puzzle. Crash-land on Earth in the 2070s, meet a squad of quirky human guides, and help Dodo earn a way home by mastering the logic that powers the future.

## About This Game

You are Dodo, a young dragon from the planet ZZS. Your ship is down, the city is watching, and the only way forward is to solve the problems that keep Earth running. Jump, explore, and interact with NPCs to trigger clever minigames that teach you real algorithmic ideas without ever feeling like homework.

## Key Features

- Story-led levels with cinematic dialogue and memorable guides.
- A growing library of algorithm minigames that feel like toys.
- A collectible Archive that fills up as you unlock new concepts.
- Bite-sized challenges that reward curiosity and experimentation.
- A warm sci-fi tone with glowing neon cities and cosmic vibes.

## How To Play

- Move through each district, talk to NPCs, and activate puzzle gates.
- Solve short, tactile minigames to unlock new algorithms.
- Track progress in the Archive and advance to the next level.

## Gameplay Loop

- Explore side-scrolling levels and find interactable obstacles.
- Solve the minigame to clear the path and unlock an algorithm.
- Watch your Archive grow and move toward the next sector of Earth.

## Example Minigames

- Scan a corrupt log entry with Sequential Search.
- Find a star ID by clicking the midpoint in Binary Search.
- Run a Bubble Sort by deciding Swap or Keep.
- Navigate a network using shortest paths and spanning trees.
- Unravel late-game challenges like backtracking and complexity gates.

## Controls

- Move: Arrow keys or A/D
- Jump: W, Up, or Space
- Interact: E
- Dialogue advance: Enter

## Story Snapshot

Earth, 2070s. A dragon from ZZS lands in the middle of a futuristic mega-city. The locals do not mind the wings, but the broken ship is a problem. Each district teaches Dodo a new algorithmic skill, until the final trial demands mastery of the big ideas behind computation itself.

## Who This Is For

- Players who love puzzle platformers with a strong narrative.
- Fans of sci-fi worlds and character-driven adventures.
- Curious minds who want to feel smart without being lectured.

## Quick Start (Local)

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
npm run preview
```

- Phaser 4 for game and UI scenes.
